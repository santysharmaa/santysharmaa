## 🚀 Featured Projects

### 📦 [Demand Forecasting & Inventory Optimization](https://github.com/santysharmaa)

**Python · Pandas · LightGBM · MLflow · Power BI**

An end-to-end supply chain analytics project that forecasts product demand for the next seven days and explores how better inventory planning can reduce stockouts.

- Engineered lag, rolling-statistic, and calendar features from historical sales.
- Compared naive and moving-average baselines with a LightGBM forecasting model.
- Evaluated predictions using WAPE and chronological validation/testing.
- Implemented safety stock, reorder point, and Economic Order Quantity (EOQ) calculations.
- Simulated inventory policies to study the trade-off between product availability and inventory holding costs.

### 🖥️ ASUS Desktop Intelligence

**React · Vite · Python · FastAPI · Electron**

A Windows desktop voice-assistant project designed to connect a modern desktop interface with Windows applications and system commands.

- Building a React-based desktop interface with microphone controls and command history.
- Developing a FastAPI backend for command processing and system integration.
- Working on microphone capture, wake-word handling, and voice-command execution.
- Integrating Windows application launching and diagnostic reporting.

### 🎵 Gesture Pilot — Hand Gesture Controlled Music System

**Python · OpenCV · MediaPipe**

A computer-vision project that uses hand gestures captured through a webcam to control music playback.

- Uses hand-tracking and gesture recognition for touchless interaction.
- Connects recognized gestures to media-control actions.
- Explores practical applications of computer vision and human-computer interaction.

### 🌍 Globetalk Companion

**Web Development · Gemini API**

A web application project that integrates Google's Gemini AI to provide an interactive AI-assisted experience.

- Connects a web interface to an LLM API.
- Explores conversational AI and practical API integration.

### 🎓 Skill Mentor
